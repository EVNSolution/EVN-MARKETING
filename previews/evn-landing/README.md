# EV&Solution 로컬 랜딩페이지

2026-10-07 공개된 https://evnsolution.kr/ 의 HTML, CSS, 이미지 및 폰트를 바탕으로 만든 로컬 시연본입니다. 별도의 프레임워크나 의존성을 추가하지 않습니다.

## 실행

저장소에서 `node scripts/preview-landing.mjs`를 실행한 뒤 `http://127.0.0.1:3022/landing/`를 엽니다. `LANDING_PORT`로 포트를 지정할 수 있습니다. 로컬 루프백 주소에만 바인딩됩니다. 종료는 Ctrl+C입니다.

## 범위

- 원본 섹션, 배경·사진·아이콘·폰트, PC/모바일 배치를 재사용합니다. 자산 출처와 SHA-256은 `asset-manifest.json`에 있습니다.
- 회사소개/차량소개/맞춤 설계/상담 신청은 원본과 같은 섹션으로 스크롤합니다.
- 보조금 계산은 원본처럼 이름·연락처·서울/경기/인천 선택 모달을 엽니다. 자동 보조금 계산식이나 결과를 추가하지 않습니다.
- 문의 폼은 입력과 동의만 검증하고, 실제 저장·전송되지 않았음을 표시합니다. 전화상담도 로컬 안내만 엽니다.
- 원본 React/Next 번들, 광고 픽셀, MLeverage 전송, 분석 스크립트 및 외부 CSS를 실행하지 않습니다. 자체 UI 스크립트만 사용하며 CSP에서 네트워크 연결과 폼 전송을 막습니다.
- 320px에서 원본의 고정 너비 비교 카드 넘침을 보정하고, 모달의 Escape/닫기/키보드 포커스, 체크박스 키보드 조작을 지원합니다.
- 원본 개인정보 안내에는 `루센트`, `채용 상담` 등 페이지 사업 내용과 다른 문구가 포함되어 있습니다. 시각 복사 범위라 본문은 보존하고 원본 재현/무전송 안내를 추가했습니다. 실제 문의 수집을 연결하려면 회사에서 문구를 확정해야 합니다.

## 검증

기존 `playwright-core`와 설치된 Chrome 또는 Edge를 사용합니다.

```powershell
node tests/landing-preview.mjs
```

필요하면 `BROWSER_EXECUTABLE`에 브라우저 실행 파일, `LANDING_SCREENSHOT_DIR`에 캡처 저장 폴더를 지정합니다. 테스트가 임시 포트로 서버를 시작하고 종료합니다. 1440/390/320px 화면 너비, 이미지, 외부 요청, 콘솔 오류, 폼 입력, 모달 닫기와 메뉴/슬라이더를 검증하며 실패 시 종료 코드가 0이 아닙니다.

기존 Marketing의 인증, 데이터베이스, 문의 API, 수집/전송 설정은 이 시연 서버에서 사용하지 않습니다. 운영 배포 또는 문의 저장 연동은 포함하지 않습니다.
